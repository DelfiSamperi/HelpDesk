# FastAPI Helpdesk API

A Helpdesk system built from scratch to streamline issue tracking and technical support.
This project is currently under development and aims to simulate a real support environment where users can create, manage, and track technical support tickets.

## Planned Features
* **User Portal:** Allows users to submit, view, and track their support inquiries.
* **Technician Dashboard:** Enables tech staff to review, update, and resolve open tickets.
* **Admin Dashboard:** Assign priorities, track tickets history.
* **Raw SQL Performance:** Powered by raw PostgreSQL queries for optimized data handling.
* **FastAPI Architecture:** Fully asynchronous endpoints utilizing automatic Pydantic data validation and auto-generated OpenAPI documentation.

## Tech Stack
* **Backend:** Python 3
* **Framework:** FastAPI
* **Database:** PostgreSQL (Raw SQL queries / `psycopg`)
* **Frontend:** React & Redux (yet to develop)

## Current Status

The project is in an early development stage.  
Initial backend structure and database configuration are being implemented.
